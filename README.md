# AI Restaurant Music Matcher

This Python script simulates an AI-powered restaurant recommender. It matches user music preferences to restaurant music genres to suggest a suitable dining experience.

## Language

`python`

## How to Run

Save the code as `restaurant_matcher.py` and run it from your terminal using `python restaurant_matcher.py`.
